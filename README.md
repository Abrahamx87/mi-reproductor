# Opsound 🎧

Reproductor de música local para Android, con la pantalla "Reproduciendo" de portada difuminada (estilo BandLab clásico).

## Descargar

Última versión (APK): https://github.com/Abrahamx87/mi-reproductor/releases/latest/download/Opsound.apk

## Qué hace

- Lee las canciones guardadas en el celular (no usa internet).
- Pantalla "Reproduciendo" con la portada borrosa de fondo.
- Sigue sonando con la pantalla apagada; controles en la notificación.
- Aleatorio, repetir, barra para adelantar y compartir canción.

## Cómo se arma

Cada vez que se sube un cambio a `main`, GitHub Actions arma el APK y lo publica en *Releases*.

Hecho con Kotlin, Jetpack Compose y Media3.
